# Tankz Audio Assets

All bundled audio is released under
[Creative Commons CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Attribution is not required, but the original authors and source pages are
recorded here for provenance.

## Sound effects

Source pack: [Basic Sound Effects](https://opengameart.org/content/basic-sound-effects)
by **n4**.

| Local file                   | Original file   | In-game use                              |
| ---------------------------- | --------------- | ---------------------------------------- |
| `public/audio/fire.mp3`      | `gunshot.mp3`   | Player and enemy cannon fire             |
| `public/audio/explosion.mp3` | `explosion.mp3` | Tank destruction and game over           |
| `public/audio/pickup.mp3`    | `coin1.mp3`     | Repair, shield, and overdrive collection |
| `public/audio/ui.mp3`        | `button.mp3`    | Upgrade selection and audio toggle       |
| `public/audio/success.mp3`   | `success.mp3`   | Wave clear and victory                   |

The source page identifies the pack as CC0 and describes the files as 320 kbps
MP3 audio.

## Music

| Local file                    | Original file   | In-game use                |
| ----------------------------- | --------------- | -------------------------- |
| `public/audio/empty-city.ogg` | `EmptyCity.ogg` | Looping wasteland ambience |

The source page identifies the track as CC0 and describes it as a loopable,
dark post-apocalyptic background track.
